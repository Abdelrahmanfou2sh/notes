# Notes App

A Flutter application for creating and managing notes with features like:

## Features
- Create, edit, and delete notes
- Search functionality
- Color coding for notes
- Local storage using Hive
- Beautiful animations
- Material Design UI

## Technologies Used
- Flutter
- Bloc Pattern
- Hive Database
- Material Design
